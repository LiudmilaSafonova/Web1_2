# Веб-сайт To-Do List, Лабораторная работа 2 

Проект выполнен на HTML, CSS и JavaScript без использования фреймворков. В приложении можно создавать, редактировать и удалять задачи, отмечать их выполненными, искать, фильтровать и сортировать по дате, менять порядок перетаскиванием и сохранять данные в `localStorage`.
